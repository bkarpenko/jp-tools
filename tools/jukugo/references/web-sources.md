# Веб-источники разбора

Реестр сайтов, с которых берутся словарные статьи. По каждому: что там лежит,
кто его достаёт — разборщик сам или Борис, — и каким порядком.

Список закрытый. Источник, которого здесь нет, в разбор не идёт: статья, добытая
где попало, неотличима от статьи, достроенной по памяти, — а именно это конвейер
и запрещает.

**Пополняется он только через Бориса.** Выяснилось по ходу, что ответа нет ни в одном
источнике реестра, — разбор останавливается на том шаге, где это выяснилось, и Борису
называются: чего не хватает, для какого шага, какие источники рекомендуются и что
каждый должен дать. Дальше разбор ждёт ответа. Одобрил — работать по ним самому, тем же
порядком, что и по остальным, и дописать их сюда.

## Кто что достаёт

**По умолчанию всё достаёт разборщик сам** — и японскую сторону, и китайскую.

| источник | что даёт | как достаётся |
|---|---|---|
| **japanknowledge.com** | 日本国語大辞典 第二版 — **и только он**; прочие ресурсы платформы игнорируются. **Японская сторона по умолчанию** | браузерная сессия поверх подписки Бориса |
| **kotobank.jp** | 精選版日本国語大辞典 — сокращённая редакция того же словаря. **Запасной путь, включается только по слову Бориса** | веб-поиск → загрузка страницы по ссылке из выдачи |
| **hanyucidian.org** | 漢語大詞典 — статья компаунда и инвентари значений знаков | браузерная сессия поверх входа Бориса (сайт за подпиской) |
| **ctext.org** | тексты классики: датировка и цитата, когда словарь молчит | браузерная сессия; сайт открытый, входа не нужно |
| **jisho.org** | JMdict — английский эквивалент японского слова или знака, и только он | веб-поиск → загрузка страницы по ссылке из выдачи |

Оба механизма расписаны ниже: «Общий порядок доступа» — про первый, разделы
источников — про второй.

## Способ не сработал — остановиться и сказать

Способ доступа может отказать по причинам, к слову отношения не имеющим: домен закрыт
сетью текущей сессии, нет входа в аккаунт, сайт лежит, загрузка возвращает ошибку.
**Это не повод обходить источник и не повод молчать.** Обходной путь — работа
по памяти или по чужому словарю — даёт разбор, который нечем проверить.

Правило одно: **остановиться на этом месте и сказать Борису** — какой источник
не дался, что было сделано, какая ошибка вернулась. Дальше разбор переходит в режим
работы по присланному: данные присылает Борис. По конвейеру самостоятельно не идти
(PIPELINE.md, «Источники» и ворота между шагами 2 и 3).

**Отказ доступа и отсутствие слова — разные вещи, и путать их нельзя.** «Сайт
не открылся» не значит «статьи нет», а из «статьи нет» не следует ничего про сайт.
В разборе пишется то, что случилось на самом деле.

**Две частые ошибки, которые выглядят похоже:**

- **«URL was not in any prior search result»** — пропущен веб-поиск. Лечится
  возвратом к нему: адрес берётся только из выдачи. Это про порядок действий.
- **`EGRESS_BLOCKED` или `403` на CONNECT** — домен закрыт сетью сессии. Поиском
  не обходится, `curl` из bash тоже не поможет. Это про сеть, и здесь остановка
  законна сразу.

## Общий порядок доступа

Для источников, куда разборщик ходит сам загрузкой страницы (не браузерной сессией):

1. **Веб-поиск** — форма запроса указана в разделе источника.
2. **Загрузка ссылки, скопированной из выдачи.** URL не собирать самому по шаблону:
   контейнер пускает только адреса, пришедшие из поисковой выдачи. Запрет технический
   и действует только здесь, при загрузке страницы. В браузерной сессии адрес набирается
   прямо, и у hanyucidian для этого есть устойчивый шаблон — см. «Адрес статьи».
3. Из страницы брать **только ту секцию, которая названа** в разделе источника.

**Из bash через `curl` не ходить** — домены словарей вне белого списка контейнера.

**Каждый открытый адрес записывается по ходу** — строка `<слово>: <ссылка>` на каждый
заход, для §5 вывода (шаг 10).

## hanyucidian.org — 漢語辭典總匯, Chinese Dictionary Compendium

### Это платформа, а не словарь

Внутри больше 160 томов и баз: 漢語大詞典, 古代汉语大词典, 现代汉语大词典, тома
大辞海 и прочее. **Поэтому «по hanyucidian» — не ссылка на словарь, и в разборе так
писать нельзя.** Называется конкретный ресурс, из которого взята статья.

Это не придирка к формулировке. Правило Б4 «сличение работает только внутри одного
словаря» проверяемо лишь тогда, когда известно, какой словарь. Основной для разбора —
**漢語大詞典**; статья из соседнего ресурса той же платформы в сличение с ним не идёт.

Что берётся отсюда:

- статья компаунда (шаг 2, такт 1) — вместе с японской закрывает шаг 3;
- инвентарь значений по каждому знаку целиком (шаги A4 и Б4). Ветке В статьи
  знаков не нужны.

### Порядок доступа

1. Открыть `https://www.hanyucidian.org/` браузерной сессией — вход уже есть.
2. Найти статью поиском внутри приложения, синтаксисом из таблицы ниже.
3. **Убедиться, что открыт нужный ресурс.** Статья одного и того же слова есть
   в нескольких словарях платформы, переключение — модуль «Resources». Берётся
   漢語大詞典; замок у ресурса значит, что он вне оплаченного плана, и это не то же
   самое, что отсутствие статьи.
4. Записать адрес статьи — для §5 вывода. Адрес устойчивый, стоит в строке браузера;
   «Cite entry» отдаёт его же (см. «Адрес статьи»).

Порядок «веб-поиск → ссылка из выдачи» здесь **не применяется**: он про загрузку
отдельных страниц, а тут работа идёт внутри приложения, за входом.

### Синтаксис поиска

Из мануала сайта (`/dictionary/default?page=userManual`), раздел Basic Search.
Примеры мануала приведены дословно.

| ввод | что находит |
|---|---|
| `學` | статьи, **начинающиеся** с 學 |
| `*學` | статьи, содержащие 學 **где угодно после первого знака** |
| `xue` | знаки с чтением xue, любой тон |
| `xue2` | знаки с чтением xué, второй тон (`xue1`, `xue3`, `xue4` так же) |
| `xue sheng`, `xuesheng` | слова с чтением xue sheng, любые тоны |
| `xue sheng1` | xue любым тоном, shēng первым |
| `5b78` | знак 學 по коду Unicode |

**Различение позиции знака встроено в поиск, и это прямо наш инструмент.** Голый
знак даёт компаунды, где он **первый**; звёздочка — где он **не первый**. Метод
требует параллелей «с тем же знаком в той же позиции» — здесь это два разных запроса,
а не фильтрация выдачи глазами. Позицию, ради которой запрос сделан, в разборе
называть: `遭*` и `*遭` дают разные множества, и какое из них смотрели, читатель
проверить не сможет.

### Прочие способы поиска

Нужны, когда знак не набирается с клавиатуры, — для разбора компаунда это редкость,
но пусть будет:

- **Radical Search** — по ключу и остатку черт. Ключ вводится или выбирается в окне;
  «Residual Strokes» фильтрует остаток, галка «±1» расширяет. **Не указан остаток —
  выдача обрезается до 50 результатов.** Знаки с отрицательным остатком сведены в «0».
- **Stroke Order Search** — по последовательности черт кнопками 一, 丨, 丿, 乛.
- **Component Search** — до четырёх компонентов; ползунок точности имеет три уровня
  от «Precise» до «Fuzzy». На высшем «見» находит только знаки с традиционным 見,
  на среднем — ещё и с упрощённым 见, на «Fuzzy» — и с визуально похожими,
  семантически не связанными: 貝, 皃. Окно выбора компонентов умеет разложить
  введённый знак на части («By Character») или показать список по числу черт
  («By Strokes»).

### Работа со статьёй

- **Resources** — модуль переключения между ресурсами, где статья тоже есть.
  Значок замка означает, что ресурс **не входит в оплаченный план**; отсутствие
  статьи в доступном ресурсе и отсутствие её вообще — разные вещи, и путать их
  в разборе нельзя.
- **More Options** — продолжение поиска от текущей статьи: «Search entries starting
  with», «Search entries containing», «Search characters with … as component».
  Это те же префикс и звёздочка, только кнопкой; для сбора китайских параллелей
  быстрее, чем набирать запрос заново.
- **Cite entry** — там же. Сайт сам собирает ссылку на статью в нескольких стилях,
  с копированием в буфер и выгрузкой в BibTeX / Endnote / RIS. Адрес в ней тот же, что
  в строке браузера, — брать любой из двух, сверив его со статьёй («Адрес статьи»).
- **Индекс ресурса** доступен прямо из статьи и позволяет ходить по разделам словаря.
  Общий список с выходными данными (серия, авторы, число томов, год, издатель) —
  страница «Dictionaries & Databases».

### Адрес статьи

У статьи есть устойчивый адрес, и он собирается по шаблону:

```
https://www.hanyucidian.org/dictionary/entry?dictionaryCode=hydcdcx&entryName=<слово>
```

`dictionaryCode=hydcdcx` — это и есть 漢語大詞典: у других ресурсов платформы код свой,
и без него шаблон ведёт в чужой словарь. «Cite entry» отдаёт ровно этот адрес, и адрес
в строке браузера после штатного поиска — тот же: выбирать между тремя способами нечего.

**`entryName` — ключ по написанию заголовка, а не по статье и не по чтению.** Всё, что
записано этими знаками, приходит на одну страницу целиком: и разные 音項 одного слова
(遭難 — одна статья с блоками ❶（—nàn）и ❷（—nán）), и разные заголовочные слова
с собственной нумерацией значений (`entryName=報` → и 報1［报］bào, и 報2［报］fù 通「赴」).

Отсюда **единственное, что требуется от разборщика:** адрес сам по себе не говорит,
какое чтение и какой номер значения процитированы, — значит это называется рядом с ним
(PIPELINE.md, §5). Промахнуться мимо нужной статьи адрес не может: он не выбирает
между заголовочными словами, он отдаёт их все.

Проверено на двух парах (遭難 — два 音項, 報 — два заголовочных слова) и одном контроле
(日課). Отдельного URL на отдельное заголовочное слово не видно нигде: ни строка браузера,
ни Cite ни разу не показали параметра, которым его можно было бы выделить.

## ctext.org — 中國哲學書電子化計劃, Chinese Text Project

### Зачем он в разборе

**Страховка от ложного «слова в Китае не было».** 漢語大詞典 описывает слова, ctext —
тексты: свыше 30 тысяч домодерновых сочинений полным текстом, открыто и бесплатно.
Сложение могло употребляться в классике и не получить отдельной словарной статьи,
и тогда по одному словарю оно уедет в ветку Б ошибочно.

Заход обязателен в трёх случаях (PIPELINE.md, шаг 2): статьи в 漢語大詞典 нет вовсе;
слово нашлось только внутри других статей; статья есть, но датировать по ней нечего.

### Порядок доступа

Браузерной сессией, как hanyucidian, только проще: сайт открытый, входа не нужно.
Дальше — полнотекстовый поиск по корпусу (см. ниже), и каждое попадание читается
в контексте.

**Предположение:** что браузерная сессия откроет ctext так же, как hanyucidian,
практикой не подтверждено — ни один разбор по нему не датировался, а из Claude Code
домен закрыт сетью. Не откроется — общее правило «способ не сработал»: остановиться
и сказать, а не решать за словарь, что слова в Китае не было.

### Границы: что здесь берут и что не берут

- **Берут датировку и цитату.** Попадание даёт текст, его время и место в нём —
  ровно то, на чём стоит шаг 3.
- **Не берут значений знаков.** Инвентарь значений на шагах A4 и Б4 остаётся
  за 漢語大詞典; выборка цитат его не заменяет — у неё нет ни нумерации, ни толкований,
  которые можно сличать.
- **Попадание не доказывает, что перед нами слово.** В вэньяне соседние знаки могут
  стоять по разные стороны синтаксической границы: конец одного оборота и начало
  следующего дают ту же пару знаков, что и компаунд. **Каждое попадание читается
  в контексте**, и в разборе сказано, чем оно признано — сложением или случайным
  соседством. Это единственное, чем ctext опасен: словарная статья про слово говорит
  сама, а текстовое совпадение — нет.

### Что на сайте есть

- **原典檢索** — полнотекстовый поиск по корпусу; в выдаче сочинение и раздел,
  из которого цитата.
- **高級檢索** — то же с отбором по эпохе и метаданным. Отсюда и берётся датировка:
  датируется сочинение, а не строка.
- **字典** — встроенный словарь по знакам, с запросом составных через «+».
  На инвентарь значений для A4/Б4 не годится (см. границы выше).

Адреса разделов человекочитаемые (`/searchbooks.pl`, `/search.pl`, `/dictionary.pl`,
`/all-texts/zh`), интерфейс переключается между 繁體 и 简体.

### Как записывать результат

Итог называется **в обоих исходах**. Нашлось — сочинение, его датировка, дословная
цитата с контекстом, и вывод, сложение это или соседство. Не нашлось — запрос,
по которому искали. Ссылка на цитату идёт в §5 вывода наравне с остальными заходами.

## Японская сторона: JapanKnowledge по умолчанию, kotobank по команде

Один и тот же словарь доступен в двух редакциях, и они не равны:

| | 日本国語大辞典 第二版 | 精選版日本国語大辞典 |
|---|---|---|
| где | japanknowledge.com, по подписке Бориса | kotobank.jp, открыто |
| что за редакция | полная | сокращённая: примеров меньше |
| когда берётся | **всегда, по умолчанию** | **только когда Борис так скажет** |

**Переключаться самостоятельно нельзя, и это главное в этом разделе.** Подписка —
вещь Бориса, а не разборщика: кончилась она или он по своим причинам хочет открытую
редакцию, он скажет это сам и сразу. Пока не сказал — японская сторона берётся
из 第二版. Молчаливый уход на kotobank даёт разбор, датированный по сокращённой
редакции там, где читатель вправе ждать полной, и по тексту это не видно.

**Платформа не открылась — это «способ не сработал», а не команда сменить источник.**
Действует общее правило раздела выше: остановиться, сказать Борису, какой источник
не дался и какая ошибка вернулась. Дальше решает он: прислать статью, скомандовать
kotobank или отложить разбор.

## japanknowledge.com — 日本国語大辞典 第二版

### Это платформа, а не словарь

Как и hanyucidian, JapanKnowledge несёт десятки справочных изданий сразу. **Поэтому
«по JapanKnowledge» — не ссылка на словарь, и в разборе так писать нельзя:**
называется ресурс, из которого взята статья, — 日本国語大辞典 第二版.

Правило то же, что у китайской стороны, и по той же причине: сличение глосс работает
только внутри одного словаря (шаг Б4), а проверить это можно, лишь когда известно,
какой словарь.

**Что даёт.** Японскую сторону разбора целиком: статью компаунда с датированными
примерами, статьи знаков для сличения глосс в ветке Б, японские параллельные
сложения и разделы 語誌 (шаг Б4).

### Порядок доступа

1. Открыть `https://japanknowledge.com/` браузерной сессией — вход уже есть
   (личная подписка, адреса статей идут через `/psnl/`).
2. Найти слово штатным поиском внутри платформы.
3. **Убедиться, что открыт нужный ресурс** — 日本国語大辞典 第二版, а не соседний
   словарь платформы и не 精選版. Замок или отсутствие ресурса в плане — это
   не то же самое, что отсутствие статьи, и в разборе это разные вещи.
4. Записать адрес статьи из строки браузера — для §5 вывода. Он имеет вид
   `https://japanknowledge.com/psnl/display/?lid=<идентификатор>`.

Порядок «веб-поиск → ссылка из выдачи» здесь **не применяется**: он про загрузку
отдельных страниц, а тут работа идёт внутри приложения, за входом.

**Синтаксис поиска в реестр пока не записан** — в отличие от hanyucidian, мануал
платформы не разбирался. Первый разбор, который пойдёт этим путём, записывает сюда
то, чем реально пользовался: форму запроса и способ ограничить выдачу одним словарём.
Пока этого нет, в разборе называется, как именно искали.

### Ходить столько раз, сколько требует расследование

За каждой параллелью, за статьёй каждого знака, за каждой уточняющей датировкой —
свой заход. Пять параллелей это пять заходов.

**Отсутствие слова в 第二版 — довод, но не доказательство.** 日国 описывает слова,
а не тексты: слово могло не получить отдельной статьи. Вывод о японской фиксации
на одном этом не строится.

**Адрес за подпиской читатель без подписки не откроет.** Это принимается: §5
существует для Бориса, у которого подписка есть, и его задача — дать ему открыть
ровно ту статью, которую цитировали.

## kotobank.jp — 精選版日本国語大辞典 (запасной путь)

**Включается только по слову Бориса** — см. раздел выше. Сам разборщик сюда
не переходит.

**Ищется здесь исключительно 日本国語大辞典, ничего кроме.** Запрос поиска:
`<слово> kotobank 精選版 日本国語大辞典`, дальше общий порядок; из страницы берётся
**только секция 精選版日本国語大辞典**. На той же странице лежат デジタル大辞泉,
世界大百科事典 и другие словари — они игнорируются целиком: датированных примеров
они не дают, а спутать их с 日国 легко, и тогда датировка разбора окажется взята
неизвестно откуда.

**Отсутствие слова в 精選版 отсутствием японской фиксации не является:** это
сокращённая редакция, и слово могло в неё не попасть. У 第二版 тот же вывод звучит
строже — см. раздел выше.

Ходить туда столько раз, сколько требует расследование: за каждой параллелью,
за статьёй каждого знака, за каждой уточняющей датировкой — свой поиск и своя
загрузка. Пять параллелей это пять поисков.

**Что делать при пустой выдаче и как сообщать о неудаче** — PIPELINE.md, шапка;
там же правило о пометке издания при датировке. Здесь не повторяется, чтобы редакции
не разошлись.

## Английский: откуда он берётся

**Ни один словарь реестра английского не содержит.** 漢語大詞典 толкует по-китайски,
日国 — по-японски, ctext даёт тексты. Поэтому английский при их глоссах переводит
разборщик, и это **норма, а не обход правила**: помечается провенанс (PIPELINE.md,
шаг 10), и на том вопрос закрыт.

**JMdict — вспомогательный и единственный словарный источник английского.** Ходить
общим порядком, запрос `<слово> jisho`, из страницы брать английские значения. Домен
может оказаться закрыт сетью сессии (`EGRESS_BLOCKED`) — тогда действует общее правило
«способ не сработал»: английский остаётся своим с пометой, разбор из-за этого
не останавливается. **Выдержка из поисковой выдачи источником не считается:** её
собирает поиск, а не словарь, и сверить её с чем-либо читатель не сможет. Границы
узкие, и выходить за них нельзя:

- **Даёт** английский эквивалент японского слова или знака — там, где он нужен словарным,
  а не своим: современное значение компаунда, японские значения знаков.
- **Не даёт инвентаря значений.** Отбор значений на шагах A4 и Б4 идёт по 漢語大詞典
  и 日国; JMdict ни датировок, ни нумерации, сверяемой с ними, не имеет.
- **Сопоставление «знач. N у 日国 ↔ строка JMdict» — вывод разборщика, а не факт.**
  Нумерация у словарей своя. Если английский поставлен к номеру значения, сказано,
  на чём сопоставление держится, — иначе английский даётся своим и помечается.

Классического китайского JMdict не покрывает вовсе, и подменять им 漢語大詞典 нельзя:
значения знака в вэньяне и значения того же знака в современном японском — разные
множества.

## Гигиена присланных страниц

Страница из-за подписки приходит вместе с состоянием входа: в сохранённом HTML
видны адрес почты, кнопка Logout, иногда куки. **В репозиторий такие файлы
не класть** — ни в `sources/`, ни куда-либо ещё; из них берётся содержание статьи,
а сам файл остаётся во временном каталоге сессии. То же про адрес почты: в разборах
и коммитах ему делать нечего.
