# Структура вывода разбора

Порядок секций фиксированный. Собран по пяти разборам: 語源, 木刀, 日課, 心地, 気配.

## Обязательная шапка

```
**[ФАКТ]** — прямо во входных материалах · **[ВЫВОД]** — следует из фактов ·
**[ГИПОТЕЗА]** — данных не хватает · **[ИНТЕРПРЕТАЦИЯ]** — мой способ прочтения
```

Для разборов, где требуется формальная строгость, используется расширенная шкала:
**Ф** факт · **Д** дедукция · **И** индукция · **О** вывод по объяснительной силе ·
**Н** не установлено.

**Разбирается пара (форма, значение)** — указывается сразу, до всего остального.

---

## §0. Ответ

Идёт первым. Всё остальное — обоснование к нему.

1. **語種** — с обоснованием (чтения; при 熟字訓 — доказательство подставной записи).
2. **Где сложено** — Япония или Китай, с аргументами и контраргументами.
3. **Ход расследования** — таблица «веха / развилка / чем разрешена».
4. **Формула сложения** — `X (значение) + Y (значение) = слово (англ / рус)`.
   Если формула не строится — сказать это прямо и объяснить почему.
5. **Развёртка** — японская подстановка + название типа + перевод на английский.
6. **Сверка** — предсказанное против засвидетельствованного, вывод о композициональности.

## §1. Значения компонентов (шаг 1 метода)

- Как отбирались значения — принцип, а не только результат.
- Выбранные значения: **дословная глосса + перевод на английский**.
- Таблица отвергнутых значений с причиной отсева для каждого.
- Что отсечено датировкой, а что значением целого — различать явно.

## §2. Перечисление связных прочтений (шаг 3) и отсечение (шаг 4)

Все связные прочтения, не только победившее. Число конкурентов — часть результата.

## §3. Тип связи (шаг 2)

Прогон по процедуре источника с цитатой правила. Указать, **какая формула сработала**
(`SCHEMA.md` §5.1).

## §8. Вольная развёртка (мнемоническая)

**Всегда последняя. Всегда под этой шапкой. Никогда внутри блока формулы.
Никогда как основание для других выводов.**

Формат:

```
> ### Вольная развёртка (мнемоническая, НЕ доказательство)
>
> [подстановка] — [перевод на английский]
> [тип]
> [в чём совпадает с реконструированной формулой]
> [где расходится — обязательно]
```

**Зачем секция нужна.** Такая развёртка полезна для запоминания слова, а иероглифическая
запись часто подсказывает удобную опору, даже когда исторически она вторична.

**Зачем жёсткий слот.** Если вольную развёртку смешать с доказанными, обесценятся все
разборы разом. Отдельная секция с неснимаемой пометкой — цена, за которую её можно держать.

**Обязательное требование 1:** указывается не только совпадение с реконструкцией,
но и **расхождение**. Мнемоника без обозначенной границы превращается в ложную этимологию.

**Обязательное требование 2:** подстановка состоит только из **реальных японских слов**
и грамматически правильна (`02_отбор_значений.md` §5Б). Если такой подстановки не
существует — секция даёт лексические опоры (существующие слова с теми же знаками
и близким значением) вместо конструкции.
