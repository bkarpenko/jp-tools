# 二字熟語の構成 — рабочая схема (v0.1, ЧЕРНОВИК)

Статус: черновик, не утверждён.
Помечено ⚠РАЗВИЛКА — требует решения до фиксации.

Источники, на которых построена схема (все лежат в `docs/kousei/`):
- `二字熟語の構成.docx` — три источника: Benesse (нач. школа), MEXT PDF (`20250331-mxt_tokubetu01-000040846_2.pdf`), manab-juku (подготовка к средней школе)
- `examples_二字熟語の構成.docx` — 319 строк размеченных примеров (317 уникальных слов)

---

## 1. Что эта схема делает и чего не делает

**Делает:** приписывает двузнаковому компаунду один структурный тип — синтаксическое отношение
между первым и вторым кандзи.

**Не делает:** ничего не говорит о композициональности. Это отдельная ось (см. §3).

---

## 2. Почему исходные источники нельзя взять как есть

Три причины. Каждая подтверждается самими источниками.

### 2.1. Источники расходятся в количестве типов

| Источник | Число типов | Есть 打消し | Есть 畳語 | Есть 接尾語 |
|---|---|---|---|---|
| Benesse | 5 + «прочее» | как «прочее» | нет | нет |
| MEXT | 5 + примечание | **нет** | как примечание | нет |
| manab-juku | 10 | да (тип 3) | да (тип 7) | да (тип 8) |

Разметка в `examples_...docx` использует 6 меток — то есть подмножество manab-juku (типы 1–6).
Значит размеченный корпус **не покрывает** 畳語, 接尾語, 故事成語, 略語, хотя они объявлены типами.

### 2.2. Критерий у всех трёх — 訓読-тест, а не структурное определение

Формулировки дословно:

> «「□○」という二字熟語があるとき、「□な○」「□の○」「□に○する」のような送り仮名をつけられれば、このタイプになります。» (修飾, manab-juku)
> «「○を□する」「○に□する」のように送り仮名をつけられれば、このタイプ» (目的語・補語, manab-juku)
> «前後の漢字をひっくり返して、後ろの漢字に「～に」「～を」をつけて読むと意味がわかりやすくなります» (Benesse)

Это тест на **узнавание**, рассчитанный на школьника, у которого уже есть носительская интуиция.
Он работает потому, что 訓読 — по сути разбор китайского синтаксиса средствами японского:
«перевернуть и прочитать снизу вверх» = обнаружить китайский порядок VO. Тест верен, но по
косвенной причине.

**Следствие для проекта:** для редких 漢語, не вошедших в японский обиход, интуиции нет — и тест
неприменим. Нужна вторая, структурная формулировка каждого типа: через часть речи компонентов и
синтаксическое отношение. 訓読-тест остаётся вспомогательной проверкой, не определением.

### 2.3. Источники внутренне противоречивы

Разбор конкретных ошибок — в `AUDIT.md`. Самое существенное: MEXT относит 拡大 и 縮小 к
«意味が似ている» и тут же глоссирует их как «ひろげる／おおきい» и «ちぢむ／ちいさい» — то есть
глагол + прилагательное. Синонимическое сложение требует одной части речи; собственный глосс
источника опровергает его же метку.

## 3. Две оси, которые нельзя смешивать

Источник manab-juku ставит в один ряд с 修飾 и 主述 категории 故事成語 (矛盾, 蛇足) и 略語 (国連).
Это категориальная ошибка.

- 矛盾 структурно — **並列** (копьё + щит). Его особенность не в структуре, а в том, что значение
  «противоречие» не выводится из сложения: оно пришло из притчи 韓非子.
- 蛇足 структурно — **修飾** (нога змеи). Та же история.

То есть 故事成語 — характеристика по оси **合成性**, а не по оси **構成**.

**Правило: 構成 и 合成性 определяются независимо. У 矛盾 есть структура (並列) И есть
некомпозициональность (аллюзивная). Одно не отменяет другого.**

略語 — другой случай: у 国連 (< 国際連合) между 国 и 連 нет вообще никакого синтаксического
отношения, знаки выдернуты из разных слов. Это законный структурный тип «отношения нет» (H1).

## 4. Инвентарь типов (фиксированный)

Восемь основных типов, 15 подтипов, плюс обязательная категория Z.

| Код | Тип | Подтипы |
|---|---|---|
| **A** | 並列 (сочинение) | A1 類義 / A2 対義 / A3 並立 |
| **B** | 修飾 (подчинение) | B1 連体 / B2 連用 / B3 方位・部位 |
| **C** | 述目 (動賓) | — |
| **D** | 述補 (動補) | D1 場所・帰着 / D2 結果 |
| **E** | 主述 | — |
| **F** | 接辞 | F1 接頭・打消 / F2 接頭・その他 / F3 接尾 |
| **G** | 畳語 | — |
| **H** | 構成関係なし | H1 略語 / H2 借音・当て字 |
| **Z** | 判定不能・複数解釈 | обязательная, не «свалка» |

### Отличия от исходных источников — и зачем

**Добавлено A3 (並立).** В корпусе размечены как 対義: 父母, 夫妻, 男女, 首尾, 公私, 授受.
父母 и 夫妻 не противоположны — они парные члены одного класса. Растягивать 対義 на них
значит потерять строгость категории. Ср. в 三字 источник уже вынужден признать 松竹梅 и 衣食住
отдельным типом «並列».

**Разделено B1 / B2.** В корпусе под одной меткой 修飾 лежат 猛獣 («свирепый зверь», определение
к существительному) и 激増 («резко возрасти», обстоятельство к глаголу). Для вопроса «что каждый
кандзи привнёс в значение» это две разные семантические операции.

**Разделено C / D.** Источник даёт слитную метку «目的語・補語». Внутри неё в корпусе лежат
настоящие 動賓 (洗顔 = 顔を洗う, 読書, 作文, 消火) и локативные комплементы
(在宅 = 宅に在る, 着席, 登山, 帰国, 渡米, 遭難). Второй кандзи в них играет разные роли:
в C — участник действия, в D1 — точка/направление.

**Добавлено D2 (結果).** Куда уходят 拡大, 縮小 — см. §2.3.

**F объединяет 打消し и 接尾語.** Это одно явление (аффиксация) с разных концов слова, а не
два независимых типа.

**故事成語 удалено как тип** — переехало на ось 合成性 (§3).

⚠РАЗВИЛКА-1: **F1 vs C для 無/不.** В классическом китайском 無 — полнозначный глагол
«не иметь», и 無罪 разбирается как 動賓 («не иметь вины»), а не как префиксальное отрицание.
Японская школьная традиция трактует его как префикс. Решение зависит от §6 — на какой момент
времени ведётся разбор.

## 5. Определения и тесты

Формат каждого типа: **структурное определение** (главное) → **части речи** → **訓読-тест**
(вспомогательный) → примеры из корпуса → с чем путают.

### A. 並列
Компоненты синтаксически равноправны. Ни один не подчинён другому. Обе позиции — одна часть речи.
Признак: перестановка компонентов даёт осмысленное (пусть и не узуальное) сочетание.

- **A1 類義** — значения близки или совпадают.
  N+N: 岩石, 河川, 山岳, 道路 · V+V: 救助, 学習, 選択, 思考 · Adj+Adj: 温暖, 寒冷, 豊富, 幼稚
- **A2 対義** — значения противопоставлены по одной шкале.
  上下, 売買, 増減, 強弱, 高低, 遠近, 難易, 貧富
- **A3 並立** — члены одного класса, не синонимы и не антонимы.
  父母, 夫妻, 男女, 首尾, 山川
  ⚠РАЗВИЛКА-2: граница A2/A3 нечёткая. 首尾 (голова/хвост) — противопоставление или пара?
  Нужен критерий. Предлагаю: A2, если между членами есть **шкала** (можно сказать «больше/меньше»,
  «выше/ниже»); A3, если только совместность.

### B. 修飾
Один компонент — вершина, другой её ограничивает. Вершина всегда **второй** знак.
Перестановка меняет значение или ломает его.

- **B1 連体** — вершина именная. Тест: «□な○」「□の○」.
  青空, 牛肉, 猛獣, 曲線, 深海, 冷水, 和食, 老人, 傑作
- **B2 連用** — вершина предикатная (глагол/прилагательное). Тест: 「□く○する」「□に○する」.
  激増, 暗示, 微笑, 前進, 漸進, 頻発, 併記, 実施, 急逝, 偶発, 互譲
- **B3 方位・部位** — вершина — позиционное существительное (上下内外前後底辺岸端).
  屋外, 屋内, 机上, 海底, 上空, 湾岸, 室内
  Формально частный случай B1, но выделен: семантический вклад второго кандзи здесь —
  чисто реляционный, и в hanyucidian эти знаки описываются отдельным классом (方位詞).

### C. 述目 (動賓)
Первый знак — предикат, второй — его прямой объект (пациенс/тема).
Тест: 「○を□する」.
洗顔, 読書, 作文, 消火, 点火, 投球, 植樹, 炊飯, 開門, 握手, 求人

### D. 述補 (動補)
Первый знак — предикат, второй — не объект, а комплемент.

- **D1 場所・帰着** — место, цель, источник. Тест: 「○に□する」.
  登山, 着席, 就職, 在宅, 帰国, 渡米, 乗車, 登校, 遭難, 潜水
- **D2 結果** — второй знак называет результат/состояние, к которому приводит действие.
  拡大 (расширить → большим), 縮小
  ⚠РАЗВИЛКА-3: D2 в японской традиции почти не выделяют, в китайской 構詞法 это стандартный
  тип. Оставляем? Мой довод — да: без него 拡大 и 縮小 приходится класть в A1 вопреки
  разным частям речи компонентов.

### E. 主述
Первый знак — подлежащее, второй — сказуемое. Тест: 「□が○する」「□が○だ」.
腹痛, 雷鳴, 日照, 地震, 円高, 骨折, 人造, 国営, 日没

### F. 接辞
Один из знаков — служебный аффикс, не вносящий самостоятельного лексического значения.

- **F1 接頭・打消** — 不 未 非 無 否 + X: 不足, 未知, 非凡, 無害
- **F2 接頭・その他** — 御 第 諸 総 全 再 初 + X
- **F3 接尾** — X + 的 性 化 然 家 者 品: 美化, 知的, 理性, 自然
  Источник сам предупреждает: «これらの語がついていても、必ずしもこの熟語の構成とは限りません。
  例：変化». То есть 化 в 変化 — не суффикс, а полнозначный компонент (A1: 変わる+化する).
  Критерий: аффикс, если он присоединяется продуктивно к открытому классу основ и не
  проходит тесты A–E.

### G. 畳語
Повтор одного знака: 刻々, 山々, 人々, 散々.
MEXT: «同じ漢字を重ね、その状態や様子を強調して表す».

### H. 構成関係なし
- **H1 略語** — знаки взяты из разных слов исходного словосочетания: 国連 (< 国際連合),
  特急, 日銀, 入試, 国体
- **H2 借音・当て字** — знаки подобраны по звучанию, значения не участвуют: 亜細亜
  ⚠РАЗВИЛКА-4: сюда же должны идти 和語, записанные кандзи? (например 大人, 今日).
  Зависит от того, входят ли они во входной поток вообще — фильтр по 語種.

### Z. 判定不能・複数解釈
Не свалка. Присваивается только с обязательным объяснением, какие типы конкурируют и почему
данных не хватает.

Прецедент из самого корпуса — единственная строка с двойной меткой:

> 借金 — «（お金を借りるの意味で）下の字が上の字の目的語・補語（借りたお金の意味で）上下が修飾・被修飾の関係»

То есть источник допускает: **одна форма — два разбора, различаемых по значению**. Это надо
закрепить как норму, а не исключение: разбор приписывается паре (форма, значение), а не форме.

## 6. Порядок применения

⚠РАЗВИЛКА-5 (блокирующая): **на какой момент времени ведётся разбор?**

Набор источников проекта (kokugodaijiten с датированными первыми употреблениями, hanyucidian
по династиям) — инструментарий диахронии. Но школьная схема §5 построена на современной
японской интуиции. Пока это не разведено, тип будет плавать.

Варианты:
- (а) разбор на момент образования — компоненты берутся в значениях, засвидетельствованных
  **до** даты первой фиксации компаунда;
- (б) разбор современного японского значения;
- (в) обе колонки раздельно, с явной фиксацией расхождения.

Мой довод — (в). Тогда «структура сохранилась / переразобралась» становится результатом,
а не шумом.

Алгоритм (после решения развилки-5):

1. Проверить 語種 и отсеять не-漢語 (→ H2 или вне схемы).
2. Проверить H1 (略語) — по данным kokugodaijiten об исходной форме.
3. Проверить G (畳語) — формально, по совпадению знаков.
4. Проверить F — по закрытому списку аффиксов, с оговоркой из §5.F3.
5. Определить части речи обоих компонентов в выбранных значениях.
6. Равноправны и одна часть речи → A, далее A1/A2/A3.
7. Первый предикатен, второй именной → C или D (по роли: пациенс vs локатив/результат).
8. Первый именной, второй предикатен → E.
9. Иначе → B, далее B1/B2/B3 по части речи вершины.
10. Если после 1–9 остаются конкурирующие разборы → Z с перечислением.

Шаг 5 — узкое место. Выбор значения кандзи из 10–20 словарных — главный источник подгонки,
см. `docs/method/` (пока не написано).

## 7. Что ещё не решено

- ⚠РАЗВИЛКА-6: 三字 и 四字 разбираются иерархически (сначала деление целого, потом внутри
  частей) — схема §4 применяется к узлам дерева. Файлы `三字熟語の構成.docx` и
  `四字熟語の構成.docx` дают только верхний уровень деления. Отдельная схема нужна?
- Критерии уверенности (высокая/средняя/низкая) — пока не формализованы.
- Правило цитирования: любая кавычка в выводе должна быть дословно найдена во входных
  материалах, иначе оформляется как рассуждение, а не цитата.
