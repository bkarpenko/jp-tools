# CN01 — 爆發 bào fā

漢語大詞典（第一版+訂補）, 第14册 › 火（灬）部 › 爆. [Статья](https://www.hanyucidian.org/dictionary/entry?dictionaryCode=hydcdcx&entryName=%E7%88%86%E7%99%BC)

- № 1 Извержение вулкана. В примерах 巴金《灭亡》十四 и 曹禺《雷雨》第一幕 стоят сравнения с вулканом. У 巴金 — 「像一座就要爆发的火山一样的激情」.
- № 2 Физический взрыв. 郭沫若《北伐途次》九 — 「在一处山凹处看见了一处地雷爆发过的地方」. Другой пример из 欧阳予倩《李秀成》第五幕.
- № 3 Столкновение, вызывающее крупные изменения. 瞿秋白《赤都心史》十七 — 「十月革命爆发，莫斯科成了世界革命的中心。」 Другой пример из 沈从文《新景与旧谊·我所见到的司徒乔先生》.
- № 4 Внезапное проявление или начало. Выражение 「突然发生」 служит опорой для разбора состава. 鲁迅《且介亭杂文·论旧形式的采用》 — 「艺术家的‘灵感’的爆发」. Также примеры из 魏巍《朝鲜人》 и 浩然《艳阳天》第一〇三章.
