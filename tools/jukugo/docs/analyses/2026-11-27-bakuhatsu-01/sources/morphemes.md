# Выдержки из статей знаков

## JP02 — 爆（バク）

日本国語大辞典 第二版, ばく〔字音語素〕, № 1. [Статья](https://japanknowledge.com/psnl/display/?lid=200203575f5dFJ79CzXo)

> (1)はぜさける。はじける。破裂する。

В разных группах приведены 爆裂 и ряд 爆笑、爆破、爆発、爆鳴.

## JP03 — 発（ハツ）

日本国語大辞典 第二版, はつ〔字音語素〕, № 4. [Статья](https://japanknowledge.com/psnl/display/?lid=20020362a999JmR8Z6ac)

> (4)でる。生じる。動き出す。起こる。起こす。

В группе с 爆発 есть 激発、瞬発、突発.

## CN02 — 爆¹（bào）

漢語大詞典（第一版+訂補）, 第14册 › 火（灬）部 › 爆. [Статья](https://www.hanyucidian.org/dictionary/entry?dictionaryCode=hydcdcx&entryName=%E7%88%86)

- № 1 「猛然破裂；迸出。」 宋苏轼《云龙山观烧得云字》诗：「野竹爆哀聲，幽桂飄寃芬。」
- № 7 「突然。参见“爆發4”。」

## CN03 — 發¹（fā）

漢語大詞典（第一版+訂補）, 第16册 › 癶部 › 發. [Статья](https://www.hanyucidian.org/dictionary/entry?dictionaryCode=hydcdcx&entryName=%E7%99%BC)

- № 1, после основной глоссы 「发射。」 добавлено 「亦指爆炸。」 清冯桂芬《上海守城记》：「礮以小礮爲彈，落地始發。是爲落地開花礮入中國之始。」
- № 4 「发生；产生。」 《汉书·刘向传》：「率二歲六月而一發，古今罕有。」 Из предшествующей части цитаты видно, что речь о солнечных затмениях.
- № 42, после основной глоссы 「发性；使性子。」 добавлено 「亦指爆发。」 赵树理《小二黑结婚》二：「于福他爹看见不像个样子，有一天发了脾气，大骂一顿。」
