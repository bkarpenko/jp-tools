# Указатель текущих исследований

Здесь хранятся новые разборы и состояние для продолжения в другом чате.
Правила работы — в [корневом AGENTS.md](../../../../AGENTS.md).
Исследовательских записей пока нет; строки добавляет агент при начале работы.

| ID / форма, чтение, значение | Статус | Версия метода (полный SHA) | Обновлено (с поясом) | Отчёт / состояние | Следующее действие или препятствие |
|---|---|---|---|---|---|

Один каталог `YYYY-MM-DD-<латинский-slug>-NN/` на пару (форма, значение).
Внутри: `report.md`, `state.md`, `sources.md`; при наличии материалов —
`sources/`, при русской редактуре — `ru.tsv`. Каталоги и пустые шаблоны заранее
не создаются. Формат отчёта берётся из выбранной версии `../../PIPELINE.md`.

При продолжении сначала прочитать состояние, затем отчёт и журнал источников,
сверить версию метода и выполнить записанное следующее действие. Статусы:
`в работе`, `ожидает данных`, `остановлено по методу`, `завершено`.
Завершение означает выполнение процедуры, а не проверку специалистом.

Указатель обновляется вместе с файлами разбора при каждом изменении статуса
или версии; незавершённая работа остаётся в таблице. Ссылки в строке ведут
к `report.md` и `state.md` соответствующего каталога.

Предложения по методу — в существующем [реестре открытого](../open-questions.md),
отдельно от принятых правил. В состоянии разбора сохраняется ссылка на предложение.

Исторические разборы находятся в [deferred/analyses/](../deferred/analyses/README.md):
это регрессионный материал, который не служит действующим шаблоном.
Образцы формата для пакета скилла — в [examples/](../../examples/).
Текущие исследования в этот каталог автоматически не переносятся.
