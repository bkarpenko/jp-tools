- Серия `2026-11-10-definition-first-01`. Пакет старта хранится в `main` репозитория `bkarpenko/jp-tools`; он не отслеживает результаты слов. Их контрольные точки передаются отдельно, по [порядку передачи](../../../../../docs/research-handoff.md).
- Базовый коммит `1ad3d417ee3e3d0f7f2ee3769d0c258ae13488a7`; blob принятого PIPELINE.md `fa0f35da06a7cc27441d496fe2496217630dbeda`. Экспериментальные [протокол](protocol.md) и [дополнение v2](protocol-v2-coverage.md) не заменяют принятую методику.
- В [манифесте](manifest.json) — SHA-256 входных материалов и происхождение нейтральных копий. Файлы `neutral/` не восстанавливать из исходников в независимом чате.
- Первый шаг для нового слова: следовать [хэнд-оффу](handoff.md), зафиксировать редакции обоих протоколов и [политику источников](access.md), затем выполнить корпусный шаг только для слова, указанного пользователем.
- Доступ к словарям проверяется в текущей сессии. Состояние авторизации не входит в этот пакет. Не открывать контрольные точки других слов и не сверяться со старыми разборами.
