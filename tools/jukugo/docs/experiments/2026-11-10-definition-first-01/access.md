# Доступ к источникам без прежних разборов

База: references/web-sources.md ревизии 1ad3d417ee3e3d0f7f2ee3769d0c258ae13488a7; безопасная производная лежит в neutral/web-sources.md. Ниже — необходимые операционные детали без результатов тестовых слов.

## Общие условия

Внешние источники — исключительно внутренний браузер (iab), управляемый CUA. Не использовать web search/fetch, curl, запросы из shell, Chrome, внешние браузеры или сетевые обходы. Читать действующую документацию CUA и брать browser ID из фактической доступности, не считать старый ID постоянным. Новый чат может не получить прежние вкладки; искать статьи заново и записывать фактические адреса.

Проверить авторизацию посещением страницы источника. Разрешён обычный вход сохранёнными браузером учётными данными, включая автозаполнение после фокуса на поле и нажатие Login. Не извлекать секреты из профилей/файлов/DOM, не просить пользователя прислать пароль, не сохранять данные аккаунта. При недоступности после предусмотренных попыток — сохранить состояние и назвать реальное препятствие; не выдавать это за отсутствие статьи.

## 日本国語大辞典 第二版 — основной японский источник

- Страница участника: https://japanknowledge.com/psnl/ . Если сессия истекла — обычная форма входа; входная страница также доступна через https://japanknowledge.com/personal/ .
- Индивидуальный поиск: https://japanknowledge.com/psnl/search/nikkoku/ . Запись знаками, 範囲=見出し, 条件=完全一致. Просмотреть все заголовки; отсылки к старшим формам того же слова проследить.
- Поле требует реального ввода: щелчок, выделение старого текста, Delete, набор, Return, затем при необходимости 検索. Проверить заголовок выдачи и фактическую строку; ошибочно склеенный ввод не считать словарным нулём.
- В CUA после выделения не фокусировать поле заново отдельной командой, иначе выделение может сброситься: pressKey(null,...) и typeText(null,...) используют текущий фокус. Использовать только документированные API текущей сессии.
- Заголовок статьи открывается в новой вкладке. В журнал идёт фактический адрес вида /psnl/display/?lid=..., полученный после клика; не готовый lid из старого разбора.
- Снимать всю статью, датированные примеры, заголовок, 語誌, 語源説, 表記, 同訓異字 при наличии. Указывать, какие изображения/кунтэн не передались текстом. Постоянно сохранять только очищенное содержание.
- 範囲=語誌 или 語源説 автоматически переключает 条件 в 部分一致 и может отключить этот список. Не пытаться менять disabled-поле. Условия OR/AND фиксировать в журнале; POST-адрес выдачи сам не воспроизводит запрос.
- Кнопка 書誌情報をコピーする может заблокировать вкладку alert; адреса из строки браузера достаточно. Не нажимать её ради цитирования. Между открытиями статей выдерживать несколько секунд. При 画像認証 остановиться; капчу самостоятельно не проходить.
- 精選版 не использовать без прямого разрешения пользователя; прочие словари платформы не становятся разрешёнными от одной общей авторизации.

## 漢語大詞典

- https://www.hanyucidian.org/ ; при необходимости обычный вход сохранёнными данными.
- Источник — именно 漢語大詞典（第一版+訂補）, а не вся платформа. Проверять строку-путь и Resources; при отсутствии нужного словаря платформа может молча показать другой.
- Поиск строки без звёздочки ищет начало; *X ищет в непервой позиции, может ограничиваться 50 заголовками. Не выводить отсутствие слова по обрезанному списку.
- Разрешён шаблон прямой статьи: https://www.hanyucidian.org/dictionary/entry?dictionaryCode=hydcdcx&entryName=<форма> . Записать адрес после открытия, ресурс, чтение и номер значения.
- При нескольких чтениях/омографах адрес отдаёт их вместе; не смешивать. Слова/знаки открывать по протоколу, не брать номер значения из прежнего отчёта.

## ctext

- Только браузерная сессия, штучные обращения, без циклической выгрузки страниц и обхода блокировок. Не переходить по Do not click this link.
- По разделу: https://ctext.org/pre-qin-and-han?searchu=<строка> и https://ctext.org/post-han?searchu=<строка> . Сегмент /zh в этих поисковых адресах не добавлять.
- Для конкретной книги выбирать наблюдаемый охват/ссылку сайта либо искать книгу https://ctext.org/searchbooks.pl?if=gb&searchu=<название> . Не придумывать URL, res и параметры фильтров. В вики поиск только внутри книги: https://ctext.org/wiki.pl?if=gb&res=<наблюдаемый-id>&searchu=<строка> .
- Записывать Search details/Matched/Total/Page и охват. Ноль требует сработавшего контроля в том же охвате. Раздел не равен всему сайту; не объявлять глобальное отсутствие по одному разделу.
- Текст проверять на настоящее слово, а не соседство знаков. Дату составления сборника отличать от атрибуции содержащегося в нём произведения; поздняя публикация не доказывает самостоятельно раннюю передачу текста.
- Счёт — не больше нескольких десятков штучных запросов на разбор, как в базовом реестре; точное число там не задано. Сохранять фактический расход. Другие источники (CBETA/DDB) применять по признакам и ограничениям нейтральной копии реестра.

## Дополнительный словарь: область прежнего согласия

Пользователь уже разрешил **デジタル大辞泉 на JapanKnowledge для 格好** в данном исследовательском контексте. Это разрешение не потеряно; заново спрашивать его для этого слова не нужно. На два других тестовых слова разрешение явно не выдавалось; постоянное расширение реестра не принято.

Для одинаковой политики источников по всей серии сначала можно запросить расширение на **責任 и 上達**, не сообщая предполагаемых результатов. До этого соблюдать существующую область, явно фиксируя неодинаковую доступность как ограничение сравнения. Можно начать разрешённую подготовку/основные словари, пока вопрос ожидает ответа. Не считать молчание согласием.

Если дополнительный источник разрешён: на JapanKnowledge 基本検索 выбрать только デジタル大辞泉 (не デジタル大辞泉プラス), поиск заголовка, проверить подпись ресурса в выдаче и статье, открыть полную статью. Не брать адрес из прошлого случая. Обычный вход в платформу разрешён. Другие словари этим не разрешаются.
