# Отложенное

Здесь лежит то, что было в рабочей части инструмента до бритвы 03.09.2026
и при разборе больше не читается. **Ничего не удалено и всё возвращаемо** —
это склад, а не мусорная корзина.

Причина переноса одна и та же у всех файлов: при разборе открывалось около
1800 строк справочного аппарата, и владелец инструмента переставал понимать,
как метод работает целиком. Инструмент, которым нельзя управлять, не лучше
инструмента, которого нет.

| файл | что в нём | почему отложен |
|---|---|---|
| `01_подход.md` | к какому моменту привязывается разбор, четыре вида события сложения | суть свёрнута в шаг 3 `метод.md`; здесь остались обоснования и разбор пограничных случаев |
| `02_отбор_значений.md` | двенадцать шагов отбора значения знака, контрольный список, уровни уверенности | в MVP-ветку вошли шесть шагов; полная процедура понадобится, когда откроется вторая ветка |
| `структура_вывода.md` | девять секций вывода, включая вольную развёртку с жёстким слотом | в MVP пять секций; вольная развёртка снята — см. ниже |
| `шкала_композициональности.md` | семь исходов разбора | в MVP три исхода: полная / есть остаток / схема неприменима |
| `разборы/` | девять разборов и файл их статусов | восемь из девяти помечены устаревшими по форме; переделывать их сейчас не решено |

## Что отменено по существу, а не просто отложено

**Вольная развёртка (мнемоническая) снята из обязательных секций.** Правило было
принято 03.09.2026 утром — слот жёсткий, отсутствие подстановки называется фразой, —
и в тот же день снято при бритве. Причина: мнемоника не относится к вопросу «складывается
ли значение из частей», а стоила отдельной секции с четырьмя требованиями. Правило
целиком сохранено в `структура_вывода.md` §8 и возвращается одним движением.

**Пятиуровневая шкала уверенности сведена к трём.** Условие для верхнего уровня —
записанная попытка опровержения по конкретному утверждению — сохранено: оно и было
содержательной частью. Различение «высокая / выше средней» по способу отсечения
конкурента (шаг 4 против шага 3Б) в MVP не воспроизводится; полная шкала —
в `02_отбор_значений.md` §7.

## Как вернуть

Файл возвращается в рабочую часть переносом обратно в `../../references/`
и упоминанием в `../../метод.md`. Разборы — в `../../examples/`. Ссылки внутри
файлов при переносе съедут: они относительные.

Порядок, в котором это осмысленно делать, — в `../mvp-план.md`.
