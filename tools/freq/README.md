# freq — частотная справка по BCCWJ

Один вопрос, один ответ: **насколько эта вещь реально употребляется** — с вердиктом,
рангом и шкалой, на которой ранг что-то значит. Значениями, разбором компонентов
и этимологией инструмент не занимается: для этого в репозитории есть другие.

Зависимостей нет — только стандартная библиотека Python 3. Данные лежат
в `../../shared/data/`, доступ к ним и знаменатели — в `../../shared/corpus.py`.

## Запуск

```
python tools/freq/freq.py 浸              один знак -> справка по кандзи
python tools/freq/freq.py 浸かる           слово     -> справка по слову
python tools/freq/freq.py 扉 唾 引き戸     список    -> сравнительная таблица
python tools/freq/freq.py --html 浸かる    то же самое страницей
python tools/freq/freq.py --check         проверка целостности данных
```

Зависимостей нет — только стандартная библиотека Python 3. Виртуальное окружение
не нужно. Ответ приходит за 1–3 секунды.

### Страница вместо текста

`--html` кладёт справку в `out/<запрос>.html` и печатает путь к файлу. Страница
самодостаточна: ни скриптов, ни внешних шрифтов, ни обращений в сеть — открывается
двойным щелчком и работает офлайн. Есть светлая и тёмная тема, длинные списки
свёрнуты.

Причина, по которой этот режим вообще появился: колонки, выровненные пробелами,
в японском тексте не держатся. Знак занимает два знакоместа, шрифт получателя знает
об этом не всегда, и таблица разъезжается — особенно в чате и на телефоне.
На странице величины показаны длиной полос, и выравнивать нечего.

Путь по умолчанию переопределяется переменной `JP_FREQ_OUT` или флагом
`-o путь/файл.html`.

Если подать не лемму, а реальное написание (`つかる`), скрипт найдёт, каким леммам
это написание принадлежит, и скажет, по чему запускать: леммы в корпусе даются
в нормализации UniDic, и `ちょっと` там лежит под `一寸`.

## Что показывает

**По списку слов** (два аргумента и больше) — сравнительная таблица: все слова
метками на одной шкале частот, ниже строки по убыванию частоты — вердикт, «раз
на столько-то слов», ранг LUW2, доля записи знаком против каны и коэффициент
SUW/LUW2. Отвечает не на вопрос «что это за слово», а на вопрос «с чего из этого
списка начинать»: слова одной полосы по частоте неразличимы, и расходятся они
записью — частотное слово может почти не показывать свой знак. Под таблицей —
вывод, собранный из чисел этого запроса.

**По кандзи** — частоту глифа в pmw, ранг в **рабочем списке** (см. ниже),
кумулятивное покрытие (сколько текста закрывают знаки до этого ранга), вердикт
по шкале, ближайших соседей по рангу вперемешку с опорными точками, разбивку
по написаниям, проверку на самостоятельное слово и крупнейшие слова гнезда.

Ранг даётся не «из 6940», а из рабочего списка — знаков, накрывающих 99,5 %
вхождений (сейчас их 2499). Полный список корпуса как знаменатель льстит: его хвост
это имена собственные, китайские цитаты и разовые написания, встретившиеся по разу.
«1833 из 6940» звучит как «верхняя четверть»; «1833 из 2499» — как «край рабочего
набора», и это правда. Граница берётся из данных на лету и при пересборке корпуса
не устаревает.

**По слову** — вердикт, ранг в LUW2 и **как часто слово попадается**: «раз на
15 тысяч слов» вместо голого pmw, плюс таблица известных слов в тех же единицах,
чтобы было с чем сравнить. Дальше: раскладка записи каной против кандзи, профиль
по жанрам (столбики по всем 13 подкорпусам BCCWJ с опорной риской «средняя
плотность по корпусу»), блок «слово или морфема» и другие леммы с тем же чтением.

**«Слово или морфема»** отвечает на вопрос одним балансом, который всегда сходится
в сто процентов: `期待` — 3 578 вхождений отдельным словом (28,6 %) плюс 8 933
внутри более длинных слов (71,4 %), итого 12 511. Оба числа из одной таблицы
(`suw` против `luw2`), поэтому вычитание законно.

Ниже в том же блоке — список составных единиц, куда слово входит, и само слово
строкой в этом же списке: проценты там считаются от того же знаменателя, что
и баланс, так что строка слова повторяет верхнюю строку баланса. Список приходит
из `luw2` и баланс только иллюстрирует — насколько он его покрывает, сказано
отдельной строкой (`期待`: 8 701 из 8 933, то есть 97,4 %; недостающее — сложения
с частотой 1, которых в `luw2` нет).

Отдельных таблиц «как длинная единица» и «как короткая единица» нет: их числа
дублировали метрики. От SUW осталось единственное, ради чего она нужна, —
сравнение абсолютных частот в разделе «Слово или морфема».

Два числа отвечают на два разных вопроса, и путать их нельзя:

* **SUW против LUW2 по абсолютной частоте** — работает ли единица внутри других слов.
  У `浸かる` коэффициент 1,02× (всегда сама по себе), у `浸透` — 7,42×
  (самостоятельным словом лишь 13 % вхождений).
* **Чем слово набрано** — виден ли знак глазу. Запись разложена на четыре корзины:
  кандзи, хирагана, катакана и прочее (латиница, цифры, символы). `浸かる` частотно,
  но хираганой пишется в 72,5 % случаев, и знак `浸` попадается лишь в четверти встреч;
  у `駄目` катакана (44,5 %) обходит хирагану (34,6 %), а `オーケー` в 91 % случаев
  набрано латинским `ＯＫ`. Если у слова несколько иероглифических написаний,
  они показаны порознь: `沢山` 2621 против `澤山` 4.
